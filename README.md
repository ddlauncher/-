## ⚡ Sobre o Projeto

O **DDLauncher** foi desenvolvido para oferecer uma experiência rápida, leve e altamente customizável na hora de jogar Minecraft (com suporte especial a versões de PvP como a 1.8.9). Ele elimina consumo desnecessário de memória RAM enquanto o jogo está aberto e traz ferramentas nativas de otimização de JVM.

---

## 🛠️ Funcionalidades

- ⚡ **Presets de Desempenho:** Configurações de JVM pré-otimizadas para extrair o máximo de FPS e estabilidade.
- 🎨 **Interface Moderna:** Construído com suporte a Modo Escuro/Claro e customização de cores.
- 📌 **Minimizar para Tray (Bandeja):** O launcher fica oculto no sistema enquanto você joga para economizar RAM.
- 🔍 **Detecção de Erros Nativas:** Diagnóstico automático para crashes comuns de Java, argumentos incorretos e falta de RAM.
- 🔐 **Autenticação Flexível:** Suporte a login Offline e integração via Microsoft OAuth.
- 🪟 **Atalhos na Área de Trabalho:** Crie atalhos `.bat` para abrir direto a sua instância favorita.

---

## 🖥️ Pré-requisitos

- **Java JDK/JRE** instalado (Java 8 para versões como 1.8.9 ou Java 17+ para versões mais recentes).
